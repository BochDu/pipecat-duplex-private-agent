# 项目提案

一句话：一台放在自己家里 Linux 小主机上的语音助手 —— 喊一声就能聊天、翻自己的笔记、安排定时任务、把消息推到微信；数据留在自己机器上。

## 它能做什么

- 四个默认名字，两种聊法
  - 喊「豆包」「千问」用端到端实时语音（听、想、说在云端一次完成）
  - 喊「大肥鱼」「GPT」用「本机负责听和说、大模型负责想」的三段式
- 名字在开口那一刻就定下来，整段对话不变
- 名字和品牌都能加
  - 想换个称呼、加一家实时语音或大模型，改一行注册表加一组凭据就行
  - 同一类服务里换品牌不用改代码
- 想换一种聊法，结束当前对话再喊另一个名字就行
- 同一时刻只跟一个模型对话，不会串音，也不会聊到一半偷偷换模型
- 像打电话一样对话，随时插话打断，不用等它说完
- 问自己笔记、日志和记忆里的事，还能按时间线回顾「我以前是怎么想的」
- 联网查资料，把文字、图片、链接推到微信
- 用一句话定定时任务（比如每天几点做什么），到点自动跑
- 说到一半被打断，已经开始的后台活照样做完，也不会重复推送
- 不管喊哪个名字，能用的本地功能都一样
  - 笔记
  - 定时任务
  - 记忆
  - 微信推送

## 边界

- 对话时的语音和必要上下文会发给云端模型，不是全离线
  - 实时语音对应的称呼发给所选的那家服务
  - 三段式对应的称呼主要发转写后的文字给所选大模型
- 请戴耳机，或用带硬件回声消除的麦克风
- 已执行的操作不能撤销；能取消的只是还没播完的回复
- 历史记忆按需取用，不会一次全塞给模型
- 不做智能家居、点歌、对外服务，也不绑定某个音箱品牌

## 隐私底线

- 笔记、记忆、任务、日志都存本地；笔记原文不出本机
- 私有内容默认禁止出网。确需回传时：
  - 只发本机生成的摘要
  - 你当场确认
  - 只对这一次对话有效
  - 并留下审计记录
- 重要且不可撤销的操作（推送、写任务、跑脚本）会先跟你确认一遍；被打断的指令不会自动执行
- 密钥只在本机注入，不写日志、不进仓库
- 只主动连外部服务，不开放外部访问端口
- 纯个人自用，没有多租户、没有对外接口

## 怎么算做成

| 阶段 | 做到什么 |
| --- | --- |
| 准备 | 机器能发声、能调音量、能收音<br/>注册表里的名字都认得准<br/>各模型的接口先单独验证通过 |
| 一 | 「豆包」能唤醒、连贯对话、随时打断、调用本地工具 |
| 二 | 「千问」接入，与「豆包」会话互斥、无串音 |
| 三 | 「大肥鱼」「GPT」接入，工具调用统一生效 |
| 四 | 四组名字任意切换无冲突，资源启停干净 |
| 五 | 定时推送、检索摘要、私有数据问答、后台任务<br/>笔记溯源与记忆时间线全量回归 |

## 运行前提

- 一台 Linux 主机（x86 / ARM，物理机、虚拟机或容器）
- 麦克风 / 扬声器 + 本地磁盘
- 容器需要直通声卡或共用同一套音频服务
- Python 和依赖版本随代码锁定
- 各模型凭据只在本机 `.env` 配置
- 模型清单与唤醒词在 `config/providers.toml`

## 最终形态

一个数据和流程都握在自己手里的私人语音终端：喊哪个名字就用哪套模型，说话就能查资料、翻自己的记录、安排自动任务，并把结果推到微信；后台能力所有模型通用。
